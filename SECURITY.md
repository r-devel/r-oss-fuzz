# Security

This repository holds the fuzz harnesses and build logic for R's
[OSS-Fuzz](https://github.com/google/oss-fuzz) project, `r`.

## Maintainers

Kevin Ushey ([@kevinushey](https://github.com/kevinushey)) maintains the
harnesses and triages R's OSS-Fuzz reports.

The OSS-Fuzz integration was filed on behalf of the R project, with support
from R Core members Simon Urbanek ([@s-u](https://github.com/s-u)) and
Heather Turner ([@hturner](https://github.com/hturner)), in
[google/oss-fuzz#15952](https://github.com/google/oss-fuzz/pull/15952).

## Reporting

R's guidance for reporting bugs, including security vulnerabilities, is at
<https://www.r-project.org/bugs.html>.
